# 🚗 Wasa3ly

### Smart Parking Assistant for EUE Students

> **Find the car → Contact the owner → Solve the parking problem**

---

## 🎯 How It Works

```text
┌─────────────────┐
│  🚘 Register    │
│   Your Car      │
│                 │
│ Student ID      │
│ Car Plate       │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 🔍 Search Car   │
│                 │
│ Enter Plate     │
│ Number          │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 👤 Find Owner   │
│                 │
│ Name + Car      │
│ Privacy Protected│
└───────┬─────────┘
        │
        ▼
   ┌────┴────┐
   │         │
   ▼         ▼
 📞 Call   💬 Message
   │         │
   └────┬────┘
        ▼
   🚗 Parking
     Solved
```
